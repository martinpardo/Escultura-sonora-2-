# Escultura-sonora-2-
Trabajos de codigo para escultura sonora, con Mozzi para ESP 32, ESP 32 C3 con PCM 5102. En la busqueda de conducta en el codigo, con  Máquina de estados propia: SILENCIO, ATAQUE, SOSTEN, RELEASE  Timbre variable: diferentes tipos de onda según el estado. Envelopes independientes: con release suave o abrupto  Comportamiento pseudoaleatorio: duraciones, frecuencias, intensidades. Usando generadores pseudo aletorios numericos
